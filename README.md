# Trade-Bit

A professional full-stack algorithmic trading terminal built with React,
Node.js and Express.

## Features

- Real-time market dashboard
- Candlestick charts
- EMA indicators
- RSI
- Order book
- Paper trading
- Strategy management
- Backtesting
- Risk controls
- Audit logs
- Responsive trading terminal

## Tech Stack

- React
- Node.js
- Express.js
- Tailwind CSS
- Socket.IO
- REST API
- JavaScript

## Project Structure

client/ - Frontend
server/ - Backend

## Installation

npm install

## Run

npm run dev

## Disclaimer

This project is a paper-trading/simulation platform and does not
execute real financial trades.
